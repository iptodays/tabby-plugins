# Changelog

## 0.1.0 — 2026-10-23

首个可用版本。

### 新增

- SSH Notes 独立管理面板：
  - 默认显示全部 SSH 连接；可关闭“显示无备注连接”只查看已有备注的连接。
  - 搜索连接名、备注、说明、IP、项目、标签。
  - 环境筛选、标签筛选、排序。
  - 一键连接、编辑备注、打开原生 SSH 配置。
  - 孤立备注显示和删除。
- 完整备注编辑器：
  - 标题、说明、环境、项目、负责人、标签、颜色。
  - 自定义终端标题、启用终端备注。
  - 创建/更新时间。
  - 未保存确认、清空备注、标签去重和上限。
- 终端标签标题：
  - 仅 SSH 终端。
  - 自定义标题 / 环境前缀 + 备注标题 / 原始标题优先级。
  - OSC 标题保护、断开重连保持、清空备注恢复。
- 设置页：
  - 常规、显示、数据管理。
  - 数据路径显示、导出/导入 JSON、导入预览、自动快照、恢复、重置设置、清除全部备注。
- 本地存储：
  - `config.yaml` 的 `sshNotes` 节点。
  - schemaVersion 1、迁移、未来版本只读。
  - 保存失败提示与重试。
- 中文界面、暗色/亮色主题兼容、Tabby 主题变量。
- 自动化测试 58 项，覆盖数据、标题、表单、面板和设置页逻辑。
- Windows 开发/诊断脚本。

### 已知限制

- 原生连接列表没有公开扩展点，备注显示在 SSH Notes 面板。
- 原生 SSH 配置弹窗没有公开插槽，备注编辑器是插件自有表单。
- 内置导入 Profile 的 ID 可能随导入源变化。
- 用户手动标签标题优先于插件标题。
