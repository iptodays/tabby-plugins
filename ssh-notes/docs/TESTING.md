## 3. 手工测试清单

以下项目建议在发布前人工执行一次：

### 3.1 数据与 UI

- [ ] 新建备注：填写标题、说明、环境、项目、负责人、标签、颜色。
- [ ] 修改备注后保存，列表和详情立即更新。
- [ ] 仅填写说明，不填写标题：保存不报错。
- [ ] 清空所有字段后保存：备注被删除。
- [ ] 点击取消且未修改：直接关闭。
- [ ] 修改后关闭：出现放弃确认。
- [ ] 删除备注：出现确认，删除后标题恢复。
- [ ] 搜索连接名、IP、项目、标签、说明。
- [ ] 按环境、标签筛选，按各字段排序。
- [ ] 孤立备注显示“SSH Profile 已不存在”，可删除。
- [ ] 空状态、加载状态、错误状态显示正确。

### 3.2 终端标题

- [ ] 有备注的 SSH 终端显示备注标题。
- [ ] 无备注的 SSH 终端保持原样。
- [ ] 本地终端标题保持原样。
- [ ] 服务器执行 `printf '\033]0;TITLE\007'` 后标签不被覆盖。
- [ ] 关闭“显示环境前缀”后标题立即更新。
- [ ] 关闭“启用终端标签备注”后标题恢复原始行为。
- [ ] 关闭“启用 SSH Notes”后标题恢复。
- [ ] 删除备注后标题恢复。
- [ ] 断开/重连后标题保持。
- [ ] 同一 Profile 多个标签互不影响。
- [ ] 用户手动重命名标签时，手动标题优先；清除后插件标题恢复。

### 3.3 导入/导出

- [ ] 导出 JSON，文件可读且包含 `schemaVersion` / `notes`。
- [ ] 导入合法 JSON，预览显示有效条数。
- [ ] 导入非法 JSON，显示具体解析错误。
- [ ] 导入缺少 `notes` 的文件，显示校验错误。
- [ ] 导入包含无效备注的文件，预览显示跳过数量。
- [ ] 合并导入保留较新的备注。
- [ ] 替换导入替换全部备注。
- [ ] 导入前自动生成快照。
- [ ] 恢复快照。
- [ ] 清除全部备注需二次确认。
- [ ] 重置设置不删除备注。
- [ ] 导出/导入不修改 SSH Profile。

### 3.4 重启、升级、禁用

- [ ] 关闭并重启 Tabby，备注仍在。
- [ ] 升级插件后 schema 迁移正常。
- [ ] 在 Settings → Plugins 禁用插件，重启后标题恢复普通行为。
- [ ] 插件加载失败时 Tabby 可进入安全模式，日志有明确错误。
- [ ] 卸载插件后备注数据仍在配置文件中。

## 4. 数据层边界测试

已在临时配置上进行：

- 手动删除 `notes` 字段：插件使用空备注集合。
- `notes` 为数组：按旧格式尝试迁移；无 `profileId` 的条目跳过并警告。
- 无效颜色：清空并警告。
- 未知环境：归为 `other` 并警告。
- 标签非数组：忽略并警告。
- 未来 `schemaVersion`：只读，不覆盖。
- JSON 文件超过 2 MB：明确拒绝。
- `config.save()` 抛错：保留内存数据，显示“保存失败 + 原因”。
